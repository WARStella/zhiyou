## 更新与复测

1. 重新上传部署完整 `cloudfunctions/api`（云端安装依赖），同时重新编译/更新小程序；本轮不需要新增 Key、数据库集合或定时器配置。
2. 验证行程 A → B → A；也可先选择 A、B，再在 A 旁点“末尾再去一次”。首程和返程分别选交通方式，逐站到达后检查下一站及旧导航清除。
3. 观察队友过期头像；与主动关闭共享分开测试。
4. 三人集合中让一人退出或被移除，其余两人到达后应可检查并确认出发；再测最后未到者退出、退出后重新加入以及原发起人退出。
5. 先断网再点击发送，恢复网络后应保留草稿；手动重试后对端只出现一条。若发送途中断网，则按界面“结果待确认”处理，重试复用编号。
6. 点击“开启活动集合通知”，记录微信弹窗或完整失败提示；再验证真实订阅者关闭小程序后能否收到通知。
7. 同队点击通知应立即看到提示；稍后再次点击同队通知也应提示。集合已结束时应明确交代，不把旧集合当作有效集合显示。

## 2026-10-18 导航补全复测

后续实现新增多方式路线预览，本地全量 1132 项通过；不替代上表真机验收状态。重新部署 api 与小程序后：

1. 分别选择步行、骑行、驾车、公交和地铁查看路线，核对所选方式、总耗时、折线和指引一致；各方式取返回方案中最快的一条。
2. 公交核对步行接驳、方向、上/下车站、途经站、进出站口、换乘与参考票价；缺失分段不连直线，无地铁或服务失败时明确提示。
3. 先完成一站，再切换下一站的出行方式；确认前保持原时间，确认后后续到达时间变化，已完成记录与实际时间保留，选择器仍可继续使用。
4. 逐站到达/跳过，检查旧路线清除；末站完成后没有旧指引。查询中退出页面或改方式，迟到响应不回填。
5. 打开地图导航后手动选择相同方式；外部地图路线可能不同，页面预览不提供实时语音或偏航重算。
