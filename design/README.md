# 智游·灵动｜小程序头像（Logo）

## 上传规格（必须满足）

| 项目 | 要求 | 本目录文件的实际情况 |
|---|---|---|
| 格式 | png / bmp / jpeg / jpg / gif | PNG ✅ |
| 大小 | 不超过 2 MB | 7–10 KB ✅ |
| 尺寸 | 建议 144 × 144 px | 精确 144 × 144 ✅ |
| 补充 | 建议用 PNG 以保持最佳效果 | ✅ |

## 选哪个

| 方案 | 语义 | 适合 |
|---|---|---|
| **A｜路径 + 终点集合点** | 一条会拐弯的行程，终点是大家汇合的集合点 | **推荐**。直接画产品在做的事，且"拐弯"暗示了动态调整 |
| **B｜定位针 + 针内集合点** | 位置与地点 | 识别度最高、最"地图应用"，但差异化最弱，同类产品用滥了 |
| **C｜Z 字路线标志** | 取「智游」首字母，用终点把字母读成一条路线 | 想要更像"品牌"而不是"功能图示"时 |
| **D｜成员汇聚集合点** | 三名成员从不同方向走向同一集合点 | 想突出**集合协同**这条创新主线时（计划书 §6.5 第一条） |

四个方案在 64 px 圆形裁切下都仍可辨认（见对比图右下角小图）。

**我的建议：A**。
理由：你们的核心表达是「先有一条可执行的路线，在现场变化中持续调整，集合之后接回原来的安排」。
A 的折线正好是这个意思——它不是一条直线，它是会拐弯的。B 只说明"这是地图类应用"，
C 需要观众先知道项目名叫智游，D 只讲了集合、没讲行程。

## 一个必须知道的显示规则

**小程序头像在微信里可能被裁成圆形**（资料页是圆的），也可能是圆角方形（列表）。
所以所有关键图形都放在**内切圆安全区**内（半径 = 46% 边长）。
`logo_<X>_circle.png` 就是圆裁预览，可以直接看出有没有被切到。

很多团队的 logo 就是在这里废掉的：图形铺满整个方形，一圆裁就切掉一角。

## 想改颜色或形状

`make_logo.py` 是可复现的生成脚本，改两处即可：

```python
C_DEEP   = (11, 60, 110)    # 背景渐变起始色（深蓝）
C_TEAL   = (0, 168, 143)    # 背景渐变结束色（青绿）
C_ACCENT = (255, 122, 69)   # 集合点橙
```

图形位置是归一化坐标（0–1），改 `route = [...]` 就能调整路径形状。

```bash
python make_logo.py     # 重新生成全部尺寸与对比图
```

脚本用 4 倍超采样后降采样实现抗锯齿（Pillow 本身不做抗锯齿），
所以边缘在小尺寸下依然干净。

## 一个刻意的设计取舍

四个方案**都没用光晕、细线、渐变描边**。第一版试过光晕，缩到 72 px 就糊成一团。

头像的真实显示尺寸常常只有 40–72 px，所以这里的规则是：
**笔画够粗、节点够大、纯色块**。缩小后仍要一眼可辨，比放大后好看重要得多。
